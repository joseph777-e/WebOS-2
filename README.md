# PixelOS

PixelOS is a small web operating system i made with main theme being pixel cause i love pixel arts, built while learning HTML, CSS and JavaScript.

## Challenges

While working on this project, the hardest part was the rendering and the fact that I don’t know JavaScript. Fortunately, HTML and CSS weren’t too hard, and I could use and understand them easily. Other than that, it was a fun project, and I really like the final result of PixelWebOS.

## Features

-Calculator: Perform quick and accurate calculations with a clean, intuitive interface.
-File Manager: Organize, move, and manage files effortlessly with a streamlined layout.
-Terminal: Access powerful command‑line tools for advanced control and automation.
-Browser Search: Look up information instantly with built‑in smart search capabilities.
-Notes: Capture ideas, reminders, and tasks in a simple, distraction‑free notes app.
